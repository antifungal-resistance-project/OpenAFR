# Pre-registration — OpenAFR validation run 2

**Written 2026-07-30, BEFORE generating decoys or running any docking for this test.**
Everything below is fixed in advance. Deviations must be recorded as deviations, not
edited into this document.

## Background

Run 1 (`work/RESULTS_validation_gate.md`) FAILED its pre-registered gate. Post-hoc
exploration of that run suggested a hypothesis: for azoles against CYP51, how closely a
molecule can bring a nitrogen to the heme iron discriminates actives from property-matched
decoys better than AutoDock Vina's affinity score (exploratory AUC 0.818 vs 0.561).

That hypothesis was generated by looking at run-1 data. It therefore cannot be tested on
run-1 data. This run tests it on molecules the hypothesis has never seen.

## Primary hypothesis (H1)

Ranking molecules by **minimum nitrogen-to-heme-iron distance** (smaller = better) will
separate held-out azole antifungals from property-matched decoys with:

    AUC     >= 0.70
    EF@1%   >= 5.0x

Both must hold. This is the same bar used in run 1; it is not being lowered.

## Falsification

If H1's AUC on the held-out set is < 0.70, the hypothesis is **not supported** and the
geometric ranking claim must be withdrawn or substantially revised. A failure here is a
publishable negative result, not a reason to re-tune and re-report.

## Held-out actives (fixed list)

Ten azole antifungals were retrieved. Three were removed as near-duplicates of training
actives (Morgan r=2 Tanimoto >= 0.70): econazole (0.79), tioconazole (0.76),
terconazole (0.75). Threshold declared before inspection of docking results.

Final held-out set (7):

    efinaconazole   luliconazole   sertaconazole   oxiconazole
    bifonazole      fenticonazole  butoconazole

None of these appeared in run 1. None contributed to forming H1.

## Decoys

50 property-matched decoys per held-out active, generated by `scripts/make_decoys.py`
with unchanged criteria: MW +/- 25, cLogP +/- 1.5, rotatable bonds +/- 2, HBD +/- 1,
HBA +/- 2, >= 1 aromatic nitrogen, Morgan Tanimoto < 0.35 against every held-out active.
Decoys are presumed inactive; this assumption is a known limitation.

## Docking protocol (fixed, identical for every molecule)

    receptor        5TZ1 chain A + heme, rigid (work/receptor.pdbqt)
    box centre      70.61, 66.28, 4.18   (crystal ligand centroid)
    box size        26 A
    exhaustiveness  32
    num_modes       20
    seed            42

Rationale, declared in advance: run 1 used a 30 A box at exhaustiveness 16 and sampled
worse than earlier 26 A / exhaustiveness 16 work. This run returns to the 26 A box and
doubles exhaustiveness so search effort is not the limiting factor. Actives and decoys are
processed by the same script with no per-molecule tuning.

## Applicability domain (declared in advance)

This rigid-receptor protocol is declared valid for ligands of <= 45 heavy atoms. Larger
ligands (posaconazole/itraconazole class) failed reproducibly in run 1, consistent with
induced fit that a rigid receptor cannot model. All 7 held-out actives are <= 36 heavy
atoms, so none are excluded — this rule removes no active from the primary analysis.

## Analysis plan

Primary (gates the result):
    mode C — rank by minimum N-Fe distance across all poses

Secondary (reported, does NOT gate):
    mode A — rank by best Vina score
    mode D — rank by (distance rank + score rank)

Metrics: AUC, EF@1/5/10%, BEDROC(alpha=20), all from `rdkit.ML.Scoring`.
Any active that produces no pose is counted as ranked last, not dropped. Dropping
unrankable actives would inflate every metric.

## Pre-committed reporting rule

The result of mode C on this held-out set will be reported as the outcome, whatever it is.
No additional ranking method invented after seeing these results may be reported as a pass.
