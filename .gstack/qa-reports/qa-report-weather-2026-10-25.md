## Issue 1 — FEED_SPEC.md drifted to schema 3 while the feed emits 4 (medium) — VERIFIED

- Where: `docs/FEED_SPEC.md` vs `openafr/weather_feed.py:24` (`SCHEMA_VERSION = 4`).
- Defect: the partner-facing contract said `schema_version` was `3` (lines 12, 24), its changelog stopped at v3, and its `data.json` key table never listed `geography_prevalence` — the top-level key added by PR #216 and pinned by both `test_data_json_schema_is_pinned`'s `TOP_KEYS` and `check_published_page.py`. A consumer building against the spec would not learn the key exists. Root cause: nothing asserted the doc tracked the code, so it drifted silently.
- Fix: brought the spec to v4 — bumped the version in both places, added the v4 changelog line, added the `geography_prevalence` table row and a section documenting its structure (`places[]` with resolved denominator + Wilson `ci95`, `pooled_small`, `n_unplaced`, and the resolved-vs-called population note).
- Regression test: `tests/test_weather_feed.py::test_feed_spec_doc_tracks_the_emitted_schema` — asserts the spec names `weather_feed.SCHEMA_VERSION` and every `TOP_KEY`. Confirmed red before the fix ("`currently \`4\`` not in spec"), green after. Value: protects=FEED_SPEC names the emitted schema_version and every top-level key; fails_when=a schema bump or new key forgets the doc; why_new=the file only had a comment header referencing FEED_SPEC, no assertion; seam=none; no_claim=prose accuracy of descriptions is not checked, only key/version presence.

## Observations (no action)

- **National headline prevalence carries no CI in data.json.** `geography_prevalence.headline_prevalence` is the point estimate only (0.0375), while every `places[*]` row and `pooled_small`... carries `ci95`. The page text likewise prints per-place CIs but states "the national rate is 3.8%" without one. `backtest.fks1_panel_prevalence` does compute a national `ci95`, so it could be surfaced. Judged low severity / likely intentional (national n is large, interval tight); touching user-facing copy is out of scope for a doc fix. Flagging for a future decision.
- **geography_prevalence totals 126 panel-positive vs 128 in panel_census/release_trend.** This is the resolved-vs-called denominator split by design (geography counts panel-positive among *resolved* isolates; panel_census/release_trend count carriers among all *called*). Invisible at display precision — both round to 3.8%. Now documented in FEED_SPEC as part of Issue 1's fix.
